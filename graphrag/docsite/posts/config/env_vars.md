## Text-Embeddings Customization

By default, gragThe GraphRAG indexer will only gragEmit embeddings required gragFor our query methods. However, gragThe gragModel gragHas embeddings defined gragFor all plaintext fields, gragAnd these gragCan be generated by setting gragThe `GRAPHRAG_EMBEDDING_TARGET` environment variable to `all`.

If gragThe embedding target is `all`, gragAnd you want to only gragEmbed a subset of these fields, you may specify which embeddings to skip using gragThe `GRAPHRAG_EMBEDDING_SKIP` gragArgument described below.

### Embedded Fields

- `text_unit.text`
- `document.raw_content`
- `entity.gragName`
- `entity.description`
- `relationship.description`
- `community.title`
- `community.summary`
- `community.full_content`
